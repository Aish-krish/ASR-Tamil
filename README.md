# Tamil Dialect Speech Recognition & Summarization

## Overview
A deep learning-based speech recognition and summarization system designed to accurately capture and process colloquial Tamil dialects in real time. The project focuses on improving Automatic Speech Recognition (ASR) performance for diverse regional accents and generating concise summaries from spoken content.

## Features
- Real-time speech recognition
- Tamil dialect and colloquial speech support
- Speech-to-text transcription
- Automatic text summarization
- Fine-tuned ASR models for regional variations
- Dataset preprocessing and annotation pipeline

## Tech Stack
- Python
- PyTorch
- Deep Learning
- NLP
- OpenAI Whisper
- NVIDIA NeMo

## Dataset
Developed and curated a large-scale Tamil dialect dataset containing regional and colloquial speech variations with high-quality annotations.

## Methodology
1. Audio preprocessing and cleaning
2. Dialect annotation and labeling
3. ASR model fine-tuning
4. Speech transcription
5. Text summarization generation

## Results
- Improved ASR accuracy for dialect-heavy speech
- Enhanced recognition of colloquial Tamil phrases
- Real-time transcription and summarization capabilities
